Privacy

Yuel Duel is a party game, not a data business. Here is everything it keeps, and for how long.

The short version

  • No accounts, no ads, no tracking, no cookies.
  • A game keeps only what the game needs: names, picks, bids, gifts and drawings.
  • Everything about a game is deleted two hours after it ends, or a day after anyone last played in it.

What a game keeps

  • The room code and the settings the host chose.
  • Each player's name (use a nickname if you like) and avatar.
  • An age, only if a player says they are under 16: the rules use it to decide who picks a duel. Older ages are not kept.
  • The gifts, chips, bids, duels and votes, plus a log of what happened, so the game can carry on if the server restarts.
  • Drawings from Sketch-Off and AI Draw Off.

How long

  • Two hours after a game ends, or 24 hours after anyone last did anything in it, the whole game is deleted from the server: names, drawings, the log, everything.
  • Your phone remembers which game you joined (in its own storage, not a cookie) so a refresh puts you back in your seat. Tap Leave, or clear the site's data, to forget it.

AI Draw Off

  • If the host turns on AI Draw Off, the two drawings in that duel are sent to the AI service the host chose (OpenAI or Google Gemini) to be judged. Nothing else about the game is sent.
  • A host who brings their own AI key: the key is kept only in the server's memory for that game. It is never saved, logged or shown to anyone, and it is forgotten when the game ends, after two hours idle, when the host taps Forget, or when the server restarts.

Children

  • Yuel Duel is meant to be played at a party with an adult hosting. Players under 16 should join with a first name or nickname and their host's say-so.
  • We never ask for an email, a phone number, a photo or a location.

What the server itself records

  • Your device's network address is used briefly, in memory, to stop anyone flooding the game with requests. It is not written down.
  • The server's logs say things like "a room was made" or "a page hit an error": room codes, counts and error messages, never names or drawings.
  • The pages load their fonts from Google Fonts, so Google sees that a browser asked for them.

Questions

Ask whoever runs this game server. To have a game deleted sooner, end it from the host console: it is gone two hours later.
